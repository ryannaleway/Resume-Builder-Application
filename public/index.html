  1. Add jobs and break each role into accomplishment-focused responsibilities.

  4. Save certifications, awards, and your Gemini API key.

            Thank You To Our Libraries

            This application was built locally with open-source libraries and tools that made the project easier to learn, organize, and ship.

            • Bootstrap 5 for responsive layout, spacing, and accessible UI components.
            • SweetAlert2 for friendly modal alerts during authentication and validation.
            • jsPDF for browser-based resume PDF export.
            • Express for RESTful Node.js web services.
            • sqlite3 for local SQLite database access.
            • Google Gemini API for AI-powered wording suggestions.
